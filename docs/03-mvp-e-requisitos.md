# 03 — MVP e Requisitos

## Objetivo do MVP

Validar se usuários percebem valor em registrar filmes/séries e receber descoberta social baseada no perfil de gosto.

## Funcionalidades priorizadas

### P0 — Essenciais

1. Criar conta / entrar.
2. Buscar filmes e séries.
3. Visualizar detalhes de um título.
4. Marcar como assistido.
5. Avaliar de 0,5 a 5 estrelas.
6. Publicar review.
7. Marcar review como spoiler.
8. Adicionar/remover da watchlist.
9. Ver diário e perfil.

### P1 — Diferenciais

10. PulseScore por critérios.
11. MoodTags.
12. PulseMatch entre usuários.
13. Feed com avaliações de amigos.

### P2 — Evoluções

14. Listas colaborativas.
15. Estatísticas avançadas.
16. Recomendações personalizadas.
17. Integração “onde assistir”.
18. Gamificação leve/conquistas.

## PulseScore

Além da nota geral, o usuário pode avaliar:

- História/roteiro.
- Atuação/personagens.
- Direção/visual.
- Trilha/áudio.

A nota geral continua simples; os critérios são opcionais e enriquecem o perfil de gosto.

## MoodTags

Exemplos de tags:

- Confortável.
- Tenso.
- Emocionante.
- Engraçado.
- Reflexivo.
- Sombrio.
- Romântico.
- Acelerado.

## PulseMatch

Indicador percentual de afinidade entre dois perfis, calculado futuramente com base em títulos avaliados em comum, proximidade de notas e preferências de gênero/tags.

## Spoiler Safe

- Autor precisa sinalizar spoiler.
- Conteúdo spoiler começa oculto.
- Usuário escolhe revelar.
- Título da obra e nota podem permanecer visíveis.

## User Stories

- Como usuário, quero buscar um título para registrá-lo rapidamente.
- Como usuário, quero avaliar um filme ou série para construir meu histórico.
- Como usuário, quero salvar algo para assistir depois.
- Como usuário, quero esconder spoilers para não prejudicar outras pessoas.
- Como usuário, quero comparar meu gosto com amigos para confiar melhor em recomendações.
- Como usuário, quero filtrar por humor para decidir o que assistir agora.

## Fora do escopo do CP4

- Backend real.
- Autenticação real.
- API de catálogo.
- Algoritmo real de recomendação.
- Banco de dados.

No CP4, essas funcionalidades são documentadas e representadas conceitualmente; a entrega técnica é o projeto Flutter inicial funcional.
