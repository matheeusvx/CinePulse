## Regra para todos

Cada integrante deve:

1. trabalhar em branch própria;
2. fazer pelo menos um commit autoral relevante;
3. abrir ou participar de um pull request;
4. revisar a entrega final antes do merge em `main`.

Isso facilita comprovar o papel desempenhado por cada membro, requisito explicitamente exigido no checkpoint.
