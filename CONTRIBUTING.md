# Contribuindo no CinePulse

## Fluxo

1. Atualize `develop`.
2. Crie uma branch com seu nome/entrega.
3. Faça commits pequenos e descritivos.
4. Abra Pull Request para `develop`.
5. Outro integrante revisa.
6. Tech Lead integra.

## Commits

- `feat:` funcionalidade.
- `fix:` correção.
- `docs:` documentação.
- `design:` identidade/UI.
- `test:` testes.
- `chore:` manutenção/configuração.
